# Nuclear Throne - Wasteland Twin-Stick Shooter

A fast-paced top-down roguelite twin-stick shooter built in V language with SDL2.

## Game Features
- **Twin-Stick Action:** WASD tactical movement coupled with mouse-aimed directional firing.
- **Multiple Weapons:** Revolver, Shotgun (5-pellet spread), Laser Rifle (piercing beam), Grenade Launcher (area explosion), Machinegun (rapid fire), and Crossbow (high damage).
- **Character Class Abilities:**
  - **Fish:** Dodge Roll for high-speed evasion and invulnerability.
  - **Crystal:** Crystal Shield to absorb and reflect enemy projectiles.
  - **Robot:** Eat Guns to digest weapons into health and ammo refills.
- **Radiation & Mutations:** Collect Rads dropped by fallen foes to level up and select mutations (*Bloodlust, Rhino Skin, Scavenger, Laser Brain, Extra Feet*).
- **Dynamic Enemy Archetypes:** Maggot swarms, Bandit riflemen, Toxic Scorpions, Stealth Assassins, and the Big Bandit Boss!

## Controls
- **W / A / S / D:** Move character
- **Mouse Movement:** Aim weapon reticle
- **Left Click:** Shoot weapon
- **Right Click / Space / Shift:** Special Character Ability (Roll / Shield)
- **E / F / Q:** Swap Weapons
- **1, 2, 3, 4, 5:** Select Mutation on level-up
- **R:** Restart
- **O:** Toggle Sound
- **ESC:** Quit

## Build & Run
```bash
v nuclearthrone
./nuclearthrone
```

Run tests:
```bash
v test nuclearthrone
```
