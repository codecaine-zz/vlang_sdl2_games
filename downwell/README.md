# Downwell - Gunboots Vertical Descent

A high-speed vertical descent roguelite action platformer built in V language with SDL2.

## Game Features
- **Gunboots Mechanics:** Shoot downward while falling to hover/recoil upward, destroy enemies, and blast destructible bricks.
- **Air Stomp Combo System:** Stomp on non-red enemies in mid-air to bounce, instantly refresh your ammo meter, and rack up combo gem multipliers.
- **Procedural Well Descent:** Navigate procedurally generated 160-tile deep levels filled with hazards, destructible blocks, gem veins, and dynamic enemies.
- **Side Shops:** Step into shop chambers to spend collected gems on health refills, max HP upgrades, and weapon modifications.
- **Multiple Weapons:** Machinegun Boots, Shotgun Boots, Laser Boots, and Burst Boots.

## Controls
- **A / D or Left / Right Arrows:** Move left / right
- **Space / Up Arrow / Z:** Jump / Fire Gunboots in mid-air
- **Down Arrow / X / Mouse Click:** Fire Gunboots
- **1, 2, 3, 4:** Buy items in Side Shop
- **R:** Restart game
- **O:** Toggle Sound
- **ESC:** Quit

## Build & Run
```bash
v downwell
./downwell
```

Run tests:
```bash
v test downwell
```
